## 1. 先理解三件事

### 1.1 Wanderer 是干什么的

Wanderer 是一个 **EVE Online 星系地图协作工具**。你把 EVE 账号授权给它，它会通过 ESI 读取你角色的实时位置，把星系、虫洞连接、信号、建筑等信息画成一张可交互的图，多人共享、实时同步。

对带队的人来说，它的核心价值是：**一张图代替一堆人在语音里喊「我在 J123456，洞通向哪里」**。

### 1.2 两层身份：站点用户 vs 地图角色

- **站点层面**：任何注册用户，登录后能看地图列表、能建图。
- **地图层面**：**每张地图有一份独立的访问列表（Access List，简称 ACL）**。ACL 决定谁能看到这张图、谁能在图上编辑。

同一个人，在 A 图里可能是 Admin，在 B 图里可能什么都不是。**权限是按图算的。**

### 1.3 五种地图角色（背下来，后面反复用）

| 角色 | 界面英文 | 能做什么 |
| --- | --- | --- |
| **管理员** | Admin | 全部权限：改地图设置、管 ACL、删图、删星系/删连线、锁定星系、追踪角色 |
| **经理** | Manager | 除「管 ACL」和「删图」外全部权限，**含锁定星系** |
| **成员** | Member | 增删星系与连线、修改星系信息、追踪角色；**不能锁定星系、不能改地图设置** |
| **访客** | Viewer | 只读：能看星系、连线、角色位置，不能改任何东西 |
| **封禁** | Blocked | 完全看不到这张图 |

两个要点：

- **封禁（Blocked）优先级最高**。一个人只要在任一匹配到的 ACL 里被设为 Blocked，其他 ACL 给的权限全部作废。
- **地图所有者（Map owner）自动是 Admin**，不需要在 ACL 里额外配置。

## 2. 注册并添加角色

### 2.1 登录

打开站点，点击登录，会跳转到 **EVE Online 官方 SSO 授权页**（界面上的说明是 "Using EVE-ONLINE SSO authorization"）。用你的 EVE 账号登录并授权即可。

> Wanderer **不会拿到你的账号密码**，只会拿到 EVE 官方授予的角色信息与只读接口令牌。

### 2.2 添加角色

进入左侧导航的 **角色（Characters）** 页面：

- 点击 **授权角色（Authorize character）** 卡片，重复上面的 SSO 流程，即可把一个角色加入。
- 需要多个角色（比如侦察号、诱导号），就重复点几次。
- 页面右上角的 **Show table** 开关，可以在「卡片视图」和「表格视图」之间切换。

> 界面上有一条提示：「All added characters will be automatically linked to your user account. You can't have same characters linked to several accounts.」
> 意思是：**一个 EVE 角色只能绑定到一个 Wanderer 账号**，不能共享。

### 2.3 只有授权过的角色才能当「地图所有者」

创建地图时要选一个 **Map owner（地图所有者）**，下拉里的候选就是**你自己已授权的角色**。所以第 2 步不做，第 3 步就建不了图。

## 3. 创建地图

### 3.1 入口

左侧导航进入 **地图（Maps）** 页面 → 点击左上角的 **创建地图（Create Map）** 卡片（一个带 `+` 的方块）。

![【图 2】地图列表页](/images/manual/help-map-list.png)

### 3.2 表单字段逐项说明

弹窗标题是 **Create Map**。字段如下：

| 字段（英文原文） | 中文含义 | 说明 |
| --- | --- | --- |
| **Name** | 地图名称 | 3–20 个字符。显示在地图卡片和顶栏上，建议用队伍/区域名，例如「WC 无人机区」。 |
| **map-slug** | 地图短名（URL 标识） | 3–40 个字符，**全站唯一**。决定地图地址：`https://你的站点/<slug>`。**建好后成员就靠这个地址进来，建议短且好记。** 若重名会提示冲突。 |
| **Public description** | 公开描述 | 显示在地图卡片上的一段介绍。没权限的人也可能看到卡片，所以别写敏感信息。 |
| **Map owner** | 地图所有者 | 从你已授权的角色里选。**该角色自动获得这张图的 Admin 权限。** |
| **Scopes** | 空间范围 | 见下方详解。 |
| **Allow only tracked characters** | 只允许被追踪的角色 | 勾选后，只有**显式开启追踪**的角色位置会显示在地图上。不勾选则所有有权限的角色位置都会出现。**人多时建议勾上**，避免地图被无关角色刷屏。 |
| **Create default access list** | 创建默认访问列表 | 勾选则自动生成一份默认 ACL 并挂到这张图。**第一次建图建议勾选。** |
| **Add an existing access list** | 挂载已有访问列表 | 把已经建好的 ACL 直接挂到这张图。适合「一套班子管多张图」。 |

> ⚠️ **Wanderer 没有「公开 / 私有」开关。** 地图的可见范围**完全由 ACL 决定**——没挂任何 ACL 时，只有地图所有者本人能看到。所以「共享给别人」这件事没有别的路径，就是配 ACL（见第 4 章）。

创建成功后会提示：`Map '<名称>' created successfully with slug '<短名>'`。

### 3.3 Scopes（空间范围）详解

Scopes 决定 **哪些类型的星系会被自动追踪并画到图上**。可以多选：

| 选项 | 中文 | 覆盖范围 |
| --- | --- | --- |
| **Wormholes** | 虫洞空间 | J 空间（J123456 这类） |
| **High-Sec** | 高安 | 安全等级 0.5 – 1.0 |
| **Low-Sec** | 低安 | 安全等级 0.1 – 0.4 |
| **Null-Sec** | 零安 | 安全等级 0.0 及以下 |
| **Pochven** | 三神裔空间 | Triglavian 空间 |

> **怎么选？**
> - 纯虫洞队 → 只勾 **Wormholes**（新建地图默认就是这个）。
> - 虫洞 + 出口在零安 → 勾 **Wormholes + Null-Sec**。这是最常见的组合。
> - 注意：勾得越多，地图上自动出现的「杂物」越多。**按需勾选，不要全勾。**

## 4. 访问控制：Access List（ACL）

ACL 是 Wanderer 权限体系的核心。**强烈建议把 ACL 和地图分开管理**：先建 ACL，再把它挂到一张或多张地图上。

### 4.1 进入 ACL 页面

左侧导航 → **访问列表（Access Lists）**。

![【图 4】Access Lists 页面](/images/manual/help-map-ACL-list.png)

### 4.2 新建 ACL

1. 点击左下角的 **新建访问列表（New Access List）**。
2. 填写 **名称（Name）** 与 **描述（Description）**。名称建议带上用途，例如「主力队 · 全权限」「外围 · 只读」。
3. 保存后回到列表页，**在左侧列表里点选这个 ACL**，右侧才会激活。

### 4.3 把成员拖进角色区（核心操作）

右侧上方有五个拖放区，**从上到下权限递减**：

```
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│    Admin    │   Manager   │   Member    │   Viewer    │   Blocked   │
│   管理员    │    经理     │    成员     │    访客     │    封禁     │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────────┘
        ← 权限从高到低 ──────────────────────────────→
```

操作方式：**把下方成员池里的人（或角色卡片）直接拖到上方某个区域**，就完成了角色分配。
界面上写着 "Drag members into the area above to assign a role"。

### 4.4 添加成员并设定角色

1. 点右上角的 **添加成员（Add Members）** → 弹出 **Add Member** 窗口。
2. 在搜索框（提示语 `Search a character/corporation/alliance`）里搜索，选中后点 **Add**。

**成员可以是三种粒度**：

- **单个角色**（Character）
- **整个军团**（Corporation）
- **整个联盟**（Alliance）

> 这是非常有用的特性：**给联盟开一张图，不用一个个加人**，把联盟加进去就行。新加入联盟的角色自动获得权限。

加进来之后，用**两种方式之一**设定角色：

- **拖拽**：把成员拖进上方五个区域之一；
- **下拉框**：直接点成员行上的角色下拉，选 `Admin` / `Manager` / `Member` / `Viewer` / `-blocked-`。

成员列表下方的分页显示为 `Page X of Y (N members)`。删除成员时会有二次确认（`Please confirm to delete member!`）。

### 4.5 ACL 本身也有 API 密钥

在新建/编辑 ACL 的弹窗里，除了 **Name**（名称）、**Description**（描述）、**Owner**（所有者）之外，还有一个只读的 **ACL API key** 字段，带 **Generate**（生成）和 **Copy**（复制）按钮。

用途：让外部系统按这份 ACL 的权限来读取数据，实现「权限跟着 ACL 走」。

### 4.6 把 ACL 挂到地图上

两种方式：

- **建图时**：在 Create Map 弹窗底部的 **Add an existing access list** 里选择。
- **建图后**：在地图列表页点该地图卡片上的**齿轮图标**（它指向 **Map Settings**），或在浏览器直接访问 `/maps/<你的slug>/settings`，在里面增删 ACL。

> 一份 ACL 可以同时挂到多张地图上，**改一次权限全部生效**。

### 4.7 一次讲清「共享地图给别人」的完整链路

```
1. 建一张 ACL  →  2. 把对方角色/军团/联盟拖进 Member 或 Viewer 区
                                    ↓
3. 把这张 ACL 挂到地图上  →  4. 把地图地址 https://站点/<slug> 发给对方
```

对方登录后，在 **Maps** 页面就能看到这张图，点进去即可。

## 5. 地图设置 Map Settings

**注意区分两个「设置」**，新手最容易搞混：

| | 地图设置（Map Settings） | 地图用户设置（Map user settings） |
| --- | --- | --- |
| 影响范围 | **整张地图，所有人** | **只影响你自己** |
| 入口 | 地图列表页卡片上的**齿轮图标**；或 `/maps/<slug>/settings` | **地图界面内**右侧栏最下方的齿轮 |
| 谁能改 | **地图所有者 / Admin**（需要 `delete_map` 权限） | 任何人（改的是自己的偏好） |

> ⚠️ **注意**：地图设置的门槛比直觉要高——**Manager 也进不去**，必须是**地图所有者或 Admin**。如果 Manager 尝试访问，会被提示 `You don't have an access.` 并跳回地图列表。

本节讲前者。后者见第 6 章。

### 5.1 页面结构

弹窗标题 **Map Settings**，左侧是一列竖排 Tab：

- **General**（通用）— 最常用
- **Balance**（余额）
- **Subscription**（订阅）
- **Import/Export**（导入导出）
- **Public Api**（公开 API）
- **Bots**（机器人集成）

> 部分 Tab 是否出现，取决于站点是否开启了对应功能。

### 5.2 General 逐项说明

| 设置项（英文原文） | 中文 | 说明与建议 |
| --- | --- | --- |
| **Map systems layout** | 地图布局方向 | 两个选项：**Left To Right**（从左到右）/ **Top To Bottom**（从上到下）。决定自动排布时星系扩散的方向。虫洞图通常用 Top To Bottom，配合 home 在上方。 |
| **Store system custom labels** | 保存星系自定义标签 | 开启后，右键给星系打的标签会存到服务器，所有人可见；关闭则只在本地。 |
| **Allow temporary system names** | 允许临时星系名 | 允许给星系起一个「临时名」（如 K162 未探明时），探明后覆盖。 |
| **Show linked signature ID as custom label part** | 把关联信号 ID 显示为自定义标签的一部分 | 把信号编号（如 ABC-123）拼进星系标签显示。 |
| **Show linked signature ID as temporary name part** | 把关联信号 ID 显示为临时名的一部分 | 同上，作用于临时名。 |
| **Show offline characters to admins & managers only** | 离线角色仅管理员/经理可见 | **人多时建议开启**，否则普通成员能看到全图所有离线角色，容易泄露行踪。 |
| **Copy map data allowed for** | 允许谁复制地图数据 | 下拉：Administrators / Managers / Members。控制右键「复制」的最低角色。 |
| **Paste map data allowed for** | 允许谁粘贴地图数据 | 下拉：Members / Administrators / Managers。控制右键「粘贴」的最低角色。 |

![【图 5】Map Settings → General](/images/manual/help-map-settings-on-map-list.png)

### 5.3 Import/Export（导入导出）

- **Export Settings**：把这张图的星系、航线、连接导出成 JSON 文件，可以用来**备份**或**迁移到另一张图**。
- **Import**：当前版本的导入入口尚未开放，**只有导出可用**。要恢复数据请使用地图内 **Map user settings → Import/Export** 里的粘贴导入（见第 6 章配套说明）。

### 5.4 Public Api（公开 API）

如果站点开启了公开 API，这里能拿到**不需要登录**就能读地图数据的密钥，方便接入第三方工具、机器人或自己的看板。

| 元素 | 说明 |
| --- | --- |
| 密钥输入框 | 显示当前密钥；还没有密钥时显示 `No Public API Key yet` |
| **Generate** | 生成一个新密钥（**会覆盖旧密钥**，用旧密钥的机器人和脚本会立刻失效） |
| **Copy** | 复制密钥到剪贴板 |
| **Enable SSE for this map** | 开关。开启后外部客户端可以通过 SSE 订阅这张图的实时事件。 |

> **公开 API 意味着持有密钥的人就能看到地图数据**，请谨慎分发；换人之后记得重新 Generate。

### 5.5 Bots（机器人集成）

用于把地图事件推送给自动化工具和机器人（例如「有人进了 home 星系就通知」）。

这里的 **Map License** 区块用于机器人的身份认证：

| 元素 | 说明 |
| --- | --- |
| 许可密钥（`License Key:`） | 默认打码显示，用 **Show / Hide** 切换明文，**Copy** 复制（会提示 `Key copied`） |
| 状态（`Status:`） | `Active`（生效）/ `Inactive`（未生效） |
| 有效期（`Expires:`） | 到期时间；没有期限时显示 `Never` |
| **Create License** | 创建许可；**需要地图订阅处于激活状态**，否则会报错。 |
| **Refresh** | 刷新许可状态 |

### 5.6 Balance / Subscription（余额 / 订阅）

> 这两个 Tab 只在站点开启了地图订阅功能时出现。**地图订阅是按「地图」购买的，不是按人**，用地图余额（Map Balance）支付。

- **Balance**：地图的 ISK 余额、充值、提现。
- **Subscription**：查看和购买订阅方案。
  - 表格列：`Subscription Plan`（方案）、`Status`（状态）、`Characters Limit`（角色数上限）、`Hubs Limit`（航线数上限）、`Active Till`（有效期至）、`Auto Renew`（是否自动续费）。
  - 没有付费订阅时提示：`No active subscriptions, using alpha plan by default.`（默认使用免费的 alpha 方案）。
  - **Add subscription**：选择周期（`1 Month` / `3 Months` / `6 Months` / `1 Year`）、角色数上限、航线数上限、是否自动续费，可填优惠码（`Promo Code`）。**同一时间只能有一个生效的付费订阅。**

**订阅激活后你能获得**（这些是实际影响功能的）：

| 能力 | 说明 |
| --- | --- |
| 追踪角色数上限提升 | 表格里的 `Characters Limit` |
| 航线（Hub）数上限提升 | 表格里的 `Hubs Limit` |
| 审计日志可查更久 | 审计页会多出 `1M` / `2M` / `3M` 三个按钮（否则只有 `HOUR` / `DAY` / `WEEK`） |
| 评论数上限提升 | 单星系评论从 30 条提升到 500 条 |
| Bots 功能 | 才能创建 Map License |

## 6. 在图上干活：编辑操作全解

这一章是日常用得最多的部分。先认识界面，再逐个讲右键菜单。

### 6.1 界面分区

```
┌──────────┬────────────────────────────────────────────┬────┐
│          │  Topbar：角色头像 | 视图切换 | 订阅栏        │ 右 │
│  左侧栏  ├────────────────────────────────────────────┤ 侧 │
│          │                                            │ 栏 │
│  (地图   │              画布（星系 + 连线）             │    │
│   列表)  │                                            │ 图 │
│          │   ┌──────────┐  ┌──────────┐               │ 标 │
│          │   │ 悬浮窗1  │  │ 悬浮窗2  │  ← Widgets    │ 栏 │
│          │   └──────────┘  └──────────┘               │    │
└──────────┴────────────────────────────────────────────┴────┘
```

- **顶栏（Topbar）**：左侧是你的角色头像，右侧是视图切换（全局/订阅）与订阅输入框。
- **右侧图标栏（RightBar）**：一排功能按钮的入口，鼠标悬停有提示。
- **悬浮窗（Widgets）**：可拖动、可缩放的小面板，显示星系详情、信号、本地人数等。
- **画布**：实际的地图。

![【图 6】地图主界面全貌](/images/manual/help-map-full-ui.png)

### 6.2 鼠标与画布操作

| 操作 | 效果 |
| --- | --- |
| **滚轮** | 缩放（缩放范围约 0.2x – 1.5x） |
| **拖拽空白处** | 平移画布（哪个键取决于主题，见下） |
| **Shift + 拖拽** | 框选多个星系 |
| **单击星系** | 选中（出现**金色四角边框**） |
| **双击 / 悬浮** | 查看星系详情 |
| **右键** | 打开上下文菜单（星系 / 连线 / 空白处各不相同） |

> **关于拖拽键位**：地图主题不同，操作方式不同（在 **Map user settings → Common → Theme** 里切换）：
> - **Default** 主题：左键拖拽＝平移画布，Shift + 拖拽＝框选。
> - **Pathfinder** 主题：左键拖拽＝框选，右键（或中键）拖拽＝平移画布。
>
> 选一个顺手的即可。**从 Pathfinder 迁移过来的老用户推荐直接选 Pathfinder 主题。**

**聚焦 vs 选中**（两个容易混淆的状态）：

- **聚焦（Focus）**：视图平移并把该星系居中，显示**天蓝色脉冲框**。
- **选中（Selected）**：显示**金色四角边框**，且不闪烁。批量操作（删除、移动）针对的是「选中」的星系。

> 在本站版本中，**聚焦时会自动把目标星系设为选中**，不需要再点一次。

### 6.7 撤销（注意：只有两处，没有通用撤销）

**这一点很重要，很多新用户会误以为有 Ctrl+Z 保底。实际上 Wanderer 没有通用的地图撤销/重做。** 目前只有两个地方能「救回来」：

**① 签名（Signature）的懒删除撤销**

在 **Signatures 悬浮窗**里删除签名时，如果开了 **Lazy delete**（懒删除），删除会先挂起而不是立即生效，此时：

- 按 **`Ctrl/Cmd + Z`** 撤销；
- 或点表头的红色撤销按钮（悬停提示 `Undo pending deletions (N) — Ns left`，意思是还剩 N 秒）。

超过倒计时就真的删掉了。

**② 审计日志里对被删星系的 Undo**

在**审计日志**页面，`System(s) Removed`（星系被删除）这一类记录上会带一个 **Undo** 按钮，点击可以按**原来的坐标**恢复被删的星系。成功后会提示 `Systems restored!`。

> ⚠️ **除此之外，以下操作都没有撤销**：移动星系、拖动布局、添加/删除连接、修改星系名称与状态、批量删除。
> 所以：**批量删除（Shift 框选 + Delete）之前一定要看清楚选中的范围。**
> 需要保底的话，靠的是第 3.3 节说的 **Copy / Paste**（复制一份再动手）以及审计日志。

## 7. 布局治理：自动排布、重排、移动星系、锁定

这一章解决的是团队协作中最痛的问题：**多人同时拖星系，图会被拖成一团乱麻。**

### 7.1 自动布局是怎么算的

Wanderer 的自动布局以 **home 星系为根**，按 **BFS（广度优先）层级扩散**排布：

- 第 0 层：home 星系
- 第 1 层：与 home 直接相连的星系
- 第 2 层：再往外一跳……
- 同一分支的星系会**水平对齐**，看起来像一棵树。

**方向（向左还是向下）**由 **Map systems layout** 决定，而**分支之间会自动隔离**，避免不同方向的星系互相压在一起。

### 7.2 一键重排（Re-arrange layout）

在星系上右键 → **Re-arrange layout**，以该星系为根重新排布整张图。

适用场景：**图被拖乱了，一键恢复秩序。**

> 出现条件：该星系是 **home** 状态，或者**它是你的订阅星系**。

### 7.3 移动星系（两阶段操作）

Wanderer 的「移动星系」是**两阶段**的，不是直接拖拽——这是为了避免误拖：

1. **第一阶段**：在要移动的星系上右键 → **Move System**。此时星系进入「待移动」状态。
2. **第二阶段**：在**目标位置的空白处**右键 → **Move `<星系名>` here**。

中途想放弃，就在空白处右键 → **Cancel Move**，或在原星系上右键 → **Cancel Move**。

> 菜单里会显示具体是哪个星系要移动（如 "Move J123456 here"），**避免多点几下之后忘了自己在搬哪个**。
> 落位时会**自动吸附到最近的空位**，不会和已有星系重叠。

**在订阅视图下，移动只改你自己的本地布局**，不会影响别人；在全局视图下才会移动给所有人看。因此**订阅视图下任何人都能移动星系**，而全局视图下需要 `UPDATE_SYSTEM` 权限（Member 及以上）。

### 7.4 锁定（Lock）——多人协作的关键

**只有 Admin / Manager 能锁定星系。**

锁定一个星系会发生三件事：

1. **它成为布局边界**。全局视图下自动布局不会跨过锁定星系重新排布，因此**不同集群（cluster）之间不会互相干扰**。
2. **它不能被删除**，除非先解锁或者管理员权限。
3. 在**别人的 home 视图**里，它当作普通节点处理（不会抢根节点的位置）。

**实战用法**：

- 你们队分了两片区域作业，各自有 home。**把两个 home 都锁上**，两边的图就互不干扰，各自 BFS 展开。
- 一条重要的战略洞，**锁定它防止被误删**。
- 有集结点（Ping）的星系**不能被删除**，需要先取消 Ping。


### 7.5 集群隔离的实战建议

| 场景 | 建议操作 |
| --- | --- |
| 单一队伍，一个家 | 把 home 设为 **Home** 状态即可，不用锁。 |
| 多队伍共用一张图 | 每个队伍的 home 都**设为 Home 并锁定**。 |
| 临时作业区 | 作业区的入口星系**锁定**，防止被自动重排冲散。 |
| 图被拖乱 | 在 home 上右键 → **Re-arrange layout**。 |

## 8. 订阅视图：让你的成员只看自己关心的星系

这是本站相对官方版**最重要的定制功能**，理解它能省下大量沟通成本。

### 8.1 问题背景

一张大图可能有几百个星系，但**每个人真正关心的往往只有自己家附近的那几十个**。全图铺开既慢又乱。

### 8.2 两种视图

顶栏上有视图切换（仅 **Admin / Manager** 能看到本切换）：

| 按钮 | 中文 | 说明 |
| --- | --- | --- |
| **全局** | 全局视图 | 看全部星系。拓扑坐标是**全队共享**的，你拖动会影响所有人。 |
| **订阅** | 订阅视图 | 只看自己订阅的星系族。**布局是你自己本地保存的**，拖乱了不影响别人。 |

> **普通成员（Member / Viewer）只能看到「订阅」视图**，没有全局视图。这是有意的：避免不熟悉全局布局的人误拖。
>
> **Admin / Manager 在订阅视图下没有订阅数量上限**，普通成员有。

### 8.3 成员怎么用订阅视图

顶栏的订阅栏（仅订阅视图可见）：

1. **输入框**：输入星系名或 J 码（如 `J144038`），在下拉结果里点选即可订阅。
2. **订阅标签（chip）**：已订阅的星系显示为一个个小标签。
   - **点击标签** → 视图聚焦到该星系。
   - **点标签上的 `×`** → 取消订阅（会有一次二次确认，防止误触）。
3. **订阅数量**：输入框右侧显示 `已用/上限`，例如 `3/5`。
   - 达到上限时输入框会禁用，并提示 **「已达订阅上限」**。
4. **订阅超过 3 个**时，标签会自动收缩成一个 **「N 个订阅 ▾」** 的下拉按钮，点开是完整列表（否则会撑破顶栏）。
5. 一个都没订阅时，会提示 **「请订阅至少一个星系」**。

> 订阅一个星系时，如果它还没在地图上，系统会**自动把它加进来**——所以订阅之后能立刻看到它。

### 8.4 「非订阅星系族」显示 / 隐藏

订阅栏里还有一组开关，标题是 **「非订阅星系族」**：

| 按钮 | 效果 |
| --- | --- |
| **显示** | 显示所有你有权限看到的星系族，包括你没订阅的。**可以在任意位置添加星系。** |
| **隐藏** | 只显示与订阅星系相连的星系族。**干净，但代价是**：与订阅断开时连自己的角色也不显示，且**不能在订阅族之外添加星系**。 |

> **推荐给成员用「隐藏」**：视野干净，专注于自己的作业区。
> **推荐给管理者用「显示」**：需要随时掌握全局动向。

![【图 9】顶栏订阅栏](/images/manual/help-topmenu-subscribe.png)

### 8.5 作为管理者，你需要知道的

- 成员订阅的星系是**按用户、按地图**分别存储的，不会互相干扰。
- **订阅上限**由站点配置决定（普通成员与只读访客的上限不同；管理员与经理不限）。**界面上永远显示真实的上限值**，不用记数字。
- 成员在订阅视图里的拖动**只写本地，不写回服务器**，所以不用担心他们把公共布局搞乱。
- 如果成员反馈「看不到某个星系了」，先让他检查是不是开了**「隐藏」**——切换成**「显示」**通常就好了。

### 8.6 成员追踪开关：`/tracking/<slug>`

订阅视图能生效的**前提是成员开启了角色追踪**。如果成员反馈「进图看不到东西」，很可能就是这个没开。

**成员自己操作**：左侧栏 → **Characters Tracking（角色追踪）** 页面。

- 左侧列出他能访问的地图，点一行选中；
- 右侧列出该地图上**他有权限追踪的角色**，勾选 **Tracked** 列的复选框即可开启；
- 未选地图时提示 `Select a map to configure character tracking`。

**管理者操作**：地图页顶部的 **地图成员页（`/<slug>/characters`）** 可以看到这张图上的活跃角色，标题形如 `<地图名> - Active Characters [N]`，每个角色显示在线/离线、是否被追踪、以及 `Active from`（从何时开始活跃）。

- 已追踪的角色后面有 **Untrack** 按钮，点一下会取消追踪。
- 页面提示原文很关键：`'Untrack' characters leading to completely remove them from the map, required manually enable the tracking by users later.`
  意思是：**取消追踪会把角色从地图上彻底移除，之后需要用户自己重新开启追踪**。所以这是一个「清理不活跃成员」的操作，不要随手点。

> 成员**第一次进入地图**时，系统会检查他是否开启了追踪，没开的话会提示：
> `You should enable tracking for all characters that have access to this map first!` 并把他引导到追踪页面。

## 9. 审计日志 Audit

### 9.1 入口

在地图列表页，该地图卡片上的 **钥匙图标**，或直接访问 `/<slug>/audit`。

### 9.2 能看什么

审计日志记录了地图上发生过的操作：谁在什么时间改了哪个星系的什么字段、增删了哪些连接等。

### 9.3 筛选

页面顶部有一排时间范围按钮：

| 按钮 | 含义 |
| --- | --- |
| **HOUR** | 最近 1 小时 |
| **DAY** | 最近 1 天 |
| **WEEK** | 最近 1 周 |
| **1M / 2M / 3M** | 最近 1 / 2 / 3 个月（需地图订阅处于激活状态） |

还有一个活动类型下拉（**Select an activity**），可以只看某一类操作。可选项如下：

| 英文选项 | 中文 |
| --- | --- |
| All Events | 全部事件 |
| System Added | 添加星系 |
| System Updated | 修改星系 |
| System(s) Removed | 删除星系（**这一项带 Undo 按钮，可恢复**） |
| Hub Added / Hub Removed | 添加/移除航线 |
| ACL Added / ACL Removed | 挂载/移除访问列表 |
| Connection Added / Connection Updated / Connection Removed | 添加/修改/删除连接 |
| Rally Point Added / Rally Point Cancelled | 设置/取消集结点 |
| Signatures Added / Signatures Removed | 添加/删除信号 |

### 9.4 用途

- **追责**：谁把 home 星系删了？
- **复盘**：这个洞是什么时候被标记成濒临坍塌的？
- **排查**：成员说「图不对」，翻日志看最近谁动了什么。

> 配合第 6.6 节的 **Last modified by** 使用：对话框看「谁最后改的」，审计日志看「完整的修改历史」。

## 10. 常见问题

**Q：为什么我建的图，别人看不到？**
A：检查三件事：① 地图上有没有挂 ACL；② 对方的角色/军团/联盟有没有在 ACL 里；③ 对方有没有真的登录。**只有 ACL 里明确列出的人才能看到图。**

**Q：为什么普通成员看不到离线角色？**
A：这是 General 里的 **Show offline characters to admins & managers only** 被开启了，属于预期行为。

**Q：图突然少了一堆星系？**
A：多半是有人切换了**订阅视图**，或者打开了**「隐藏非订阅星系族」**。点回**「全局」**或切到**「显示」**看看。

**Q：为什么「Move System」点了没反应？**
A：「移动星系」是**两阶段**的。点了 **Move System** 之后，还要在**目标位置的空白处右键**，选 **Move `<星系名>` here**。

**Q：为什么有些连线没有「Set as Bridge」？**
A：这个选项**只在零安 ↔ 零安的连线上出现**。

**Q：为什么删不掉某个星系？**
A：三种可能：① 它被**锁定（Lock）**了，先解锁；② 它上面有**集结点（Ping）**，先取消 Ping；③ 你的角色在该图上没有 `DELETE_SYSTEM` 权限（Viewer 做不到，Member 及以上可以）。

**Q：星系和连线会自动过期消失吗？**
A：会。**虫洞信号 1 天过期，其他信号 2 天过期**；隐藏超过 1 天的星系和连线会被自动清理。这是为了避免地图被历史数据淹没。

**Q：成员说「我的角色不见了」？**
A：按顺序排查：① 该角色有没有开启**追踪**；② 地图创建时有没有勾 **Allow only tracked characters**；③ 成员当前是不是在**「隐藏」**模式且角色所在的星系族与订阅断开。

**Q：多张图可以用同一份 ACL 吗？**
A：可以，而且是**推荐做法**。先建 ACL，再挂到多张图上，改一次权限全部生效。
