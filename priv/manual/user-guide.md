# Wanderer 使用手册 · 普通用户篇

> 面向：**加入别人地图、看图和协作的成员**（Member / Viewer）。
> 不涉及：建图、管权限、服务器与站点管理。
> 界面语言：本站界面以英文为主，正文写成「中文名（English Label）」的形式，方便你对照屏幕上的按钮。
> 看截图：**点一下图片即可全屏放大**；在弹窗里再点一下图片，可在「适应屏幕」和「原始尺寸」之间切换（界面上的小字要原始尺寸才看得清）。按 `Esc` 或点图片以外的空白处关闭。

## 1. 五分钟上手

如果你只想尽快用起来，按这个顺序做：

1. **登录**（用 EVE 账号授权）。
2. 在 **角色（Characters）** 页面**授权你的角色**——没有角色什么都做不了。
3. 找队长要**地图地址**（形如 `https://站点/xxxx`），打开它。
4. 进入地图后，**在右上角订阅栏里订阅一个星系**（通常是你家洞的 J 码）。
5. 打开 **角色追踪（Tracking）**，把你要上报位置的角色勾上。
6. 完成。地图上会出现你的星系族和你的角色位置。

> **第 4、5 步是新手最常漏掉的两步**，漏了就会觉得「这地图怎么是空的」。详见第 5 章和第 9 章。

## 2. 登录与添加角色

### 2.1 登录

打开站点 → 点击登录 → 跳转到 **EVE Online 官方 SSO 授权页**。用 EVE 账号登录并授权。

> Wanderer **拿不到你的账号密码**，只会拿到 EVE 官方授予的角色信息和只读接口令牌。

### 2.2 添加角色

左侧导航 → **角色（Characters）** 页面 → 点击 **授权角色（Authorize character）** 卡片（图标是一个带 `+` 的方块，下方小字 `* Using EVE-ONLINE SSO authorization`）→ 走一遍 SSO。

**你有几个角色就加几次**（比如主号、侦察号、诱导号）。每个角色都会显示：

- 立绘、角色名
- `Corporation:`（公司）、`Alliance:`（联盟）
- `Location:`（当前所在星系）
- `Ship:`（当前船型）
- `Balance:`（钱包余额，如果站点开启了钱包追踪）

每张卡片右上角有三个按钮：**查看角色主页（View Profile）**、**重新授权（Refresh Authorization）**、**删除角色（Delete Character）**。

> 如果出现红色警告图标，悬停提示 `Invalid token. Please refresh authorization`，说明**授权过期了**，点「重新授权」走一遍 SSO 即可。

页面右上角的 **Show table** 开关可以在「卡片视图」和「表格视图」之间切换。

> ⚠️ 页面上方的提示很重要：`All added characters will be automatically linked to your user account. You can't have same characters linked to several accounts.`
> 意思是：**一个 EVE 角色只能绑定一个 Wanderer 账号**，不能和别人共用同一个角色。

![【图 1】角色页面](/images/manual/help-characters-page.png)


### 2.3 你的角色主页

点角色卡片上的 **View Profile**，进入 `角色主页`：

- 顶部是你的角色立绘、在线状态（绿点 = `Online`）、公司、联盟。
- 右上两个外链按钮：**zKill**（跳 zkillboard 查击杀）、**EVE Who**（跳 evewho 查历史）。
- **About** 区块：**只有你自己能编辑**（点铅笔图标），可以写一段自我介绍。编辑器支持 Markdown，最多 10000 字。保存成功提示 `Description updated`。

> 这些信息会显示给同地图的其他成员，方便大家认识彼此。

## 3. 进入地图

### 3.1 从地图列表进入

左侧导航 → **地图（Maps）** 页面。你能看到的地图**都是别人给你开了权限的**。

每张地图卡片显示：

- 地图名称与描述
- 这张图关联的**访问列表标签（ACL）**——点击可以查看
- **`Tracked Characters:`** + 数字，表示这张图上被追踪的角色数量

点卡片即可进入地图。

> 如果你在 Maps 页面**看不到某张图**，说明你的角色/军团/联盟不在那张图的访问列表里，**找队长加权限**，自己没办法。

### 3.2 在地图内切换地图

如果你有多张图的权限，不必回列表页——地图左上角有个下拉框（提示语 `Select a map...`），可以直接切换。

![【图 2】地图列表](/images/manual/help-map-list.png)

### 4.1 整体布局

┌──────────┬────────────────────────────────────────────┬────┐

│  左侧栏  ├────────────────────────────────────────────┤ 侧 │

│          │   ┌──────────┐  ┌──────────┐               │ 标 │
│          │   │ 悬浮窗1  │  │ 悬浮窗2  │  ← Widgets    │ 栏 │
│          │   └──────────┘  └──────────┘               │    │
└──────────┴────────────────────────────────────────────┴────┘

### 4.2 两种界面模式

地图界面有**两种排布方式**，通过右侧栏最下方的 **`Switch to menu`**（切到菜单栏）按钮切换：

| 模式 | 顶栏长什么样 | 什么时候用 |
| --- | --- | --- |
| **紧凑模式**（默认） | 顶栏只有你的角色头像和订阅栏，所有功能图标**竖排在右侧栏** | 屏幕小、想让画布更大 |
| **菜单模式** | 顶栏横向平铺搜索框、视图切换、订阅栏，最右侧一个 **`Map Menu`** 按钮收起所有功能 | 屏幕大、想一眼看到所有入口 |

两种模式下功能**完全一样**，只是摆放位置不同。切换开关在地图用户设置里的 **`Enable compact map menu bar`**。

![【图 3】地图主界面全貌](/images/manual/help-map-full-ui.png)

### 4.3 鼠标操作

| 操作 | 效果 |
| --- | --- |
| **滚轮** | 缩放 |
| **拖拽空白处** | 平移画布 |
| **Shift + 拖拽** | 框选多个星系 |
| **单击星系** | 选中 |
| **双击连线** | 打开这条洞的通行记录侧栏 |
| **右键** | 打开上下文菜单 |

> **拖拽键位取决于主题**（在 **Map user settings → Common → Theme** 里切换）：
> - **Default** 主题：左键拖拽 = 平移画布；Shift + 拖拽 = 框选。
> - **Pathfinder** 主题：左键拖拽 = 框选；右键（或中键）拖拽 = 平移画布。
>
> 从 Pathfinder 迁移过来的老用户建议直接选 **Pathfinder** 主题，肌肉记忆不用改。

**「聚焦」和「选中」是两回事**：

- **聚焦（Focus）**：视角平移并居中到某个星系，显示**天蓝色脉冲框**（会闪）。
- **选中（Selected）**：显示**金色四角边框**（不闪）。

> 在本站版本中，**聚焦时会自动把该星系也设为选中**，不用再点一次。

## 5. 订阅星系（最重要的一节）

这一节是本站**区别于官方版的核心机制**，也是新手最容易困惑的地方。**请务必读完。**

### 5.1 为什么会有「订阅」

一张大图可能有几百个星系，但你真正关心的往往只有**自己家附近的那几十个**。所以本站把地图分成了两种视图，并默认让普通成员只看自己订阅的部分。

**普通成员（Member / Viewer）只有「订阅视图」，没有全局视图。** 这是有意的设计——避免不熟悉全局布局的人把公共地图拖乱。

### 5.2 订阅栏在哪

**地图页顶栏**上，从左边数第二个区域（如果你看不到视图切换按钮，那是正常的，见下）。

订阅栏从左到右有三部分：

```
[非订阅星系族 显示|隐藏]   [输入星系名/代码订阅，如 J144038]  [已订阅的星系标签...]
```

> **如果你是管理员或经理**，订阅栏最左边还会多一组 **「全局 / 订阅」** 按钮用于切换视图。**普通成员没有这组按钮**，你看到的就是订阅视图。

### 5.3 怎么订阅一个星系

1. 在输入框里输入**星系名或 J 码**，例如 `J144038`。
2. 下方会出现搜索结果（最多 20 条），**点击一项即完成订阅**。
3. 订阅成功后，输入框右侧会显示 **`已订阅数/上限`**，例如 `2/10`。

> **订阅一个还没在地图上的星系时，系统会自动把它加进来**，所以订阅完立刻就能看到。
> 如果它原本不在图上、又加不进来，标签会退而显示星系的 J 码（而不是一串数字 ID）。

### 5.4 订阅标签（chip）怎么用

已订阅的星系会显示成一个个小标签：

| 操作 | 效果 |
| --- | --- |
| **点击标签** | 视图**聚焦**到该星系（同时选中） |
| **点标签上的 `×`** | **取消订阅**（会先弹确认框 `取消订阅该星系？`，防止误触） |

**订阅超过 3 个时**，标签会自动收缩成一个 **「N 个订阅 ▾」** 的下拉按钮，点开是完整列表，在里面同样可以点击聚焦或 `×` 取消。

> 一个都没订阅时，会提示 **「请订阅至少一个星系」**。

### 5.5 订阅上限

| 你的角色 | 订阅上限 |
| --- | --- |
| 管理员 / 经理（Admin / Manager） | 不限 |
| 成员（Member） | 有限额（默认 10） |
| 访客（Viewer） | 有限额（默认 1） |

具体数值由站点配置决定，**界面上永远显示真实值**（就是那个 `已用/上限`），不用记。

达到上限时，输入框会变成灰色并提示 **「已达订阅上限」**，取消一个已有订阅才能再加。

### 5.6 「非订阅星系族」：显示 还是 隐藏

订阅栏左边有一组开关，标题是 **「非订阅星系族」**：

| 按钮 | 效果 | 适合谁 |
| --- | --- | --- |
| **显示** | 显示所有你有权限看到的星系族，包括你没订阅的。**可以在任意位置添加星系。** | 想看全局动向的人 |
| **隐藏** | **只显示与订阅星系相连的星系族**。视野最干净，但代价是：**与订阅断开时连自己的角色也不显示**，而且**不能在订阅族之外添加星系**。 | 想专心干活的人 |

**「隐藏」模式下想做订阅范围外的事，右键菜单里的 `Add System` 会变成灰色不可点**，悬停会提示：

> `隐藏模式下不可添加星系，请先切换为「显示」`

**看到这个提示，就切回「显示」即可。**

> 💡 **推荐设置**：日常作业用**「隐藏」**，视野清爽；需要关注全局时切**「显示」**。

### 5.7 刚进地图时的空视图提醒

**如果你还没订阅任何星系，地图是空的**，并会弹出一个中文提示框：

> **订阅提醒**
> 进入地图前，请先在右上角订阅星系（通常为母洞星系编号）。
> 订阅后即可查看对应星系路径。
> ［知道了］

看到这个弹窗，**照做就行**——去订阅栏输入你家洞的 J 码。

![【图 4】顶栏订阅栏](/images/manual/help-topmenu-subscribe.png)

## 6. 看懂地图：星系与连线

### 6.1 星系节点上的信息

一个星系方块上可能显示：

| 元素 | 含义 |
| --- | --- |
| **星系名 / 别名** | 默认是 J 码；如果有人设了别名，显示别名 |
| **安全等级 / 星系等级** | 例如 C5、HS、LS、NS |
| **Tag 标记** | 一个字母或数字（如 `A`、`3`），用于语音里快速指代 |
| **自定义标签** | 例如「主基地」 |
| **区域名** | 星系所在的星域 |
| **静态虫洞** | 该星系的静态洞类型 |
| **效应色块** | 虫洞效应 |
| **在线人数** | 当前在该星系的角色数 |
| **锁定图标（🔒）** | 该星系被管理者锁定了 |
| **航线标记** | 该星系在公共航线上 |
| **重叠角标** | 两个星系位置重叠时会显示，悬停提示「与 XXX 重叠」 |

**选中** = 金色四角边框（不闪）；**聚焦** = 天蓝色脉冲框（会闪）。

### 6.2 连线上标注的信息

虫洞连线上会显示这条洞的实时状态：

| 标注 | 含义 |
| --- | --- |
| **剩余寿命** | `1H` / `4H` / `4.5H` / `16H` / `24H` / `48H` |
| **质量状态** | **Verge**（红，濒临坍塌）/ **Half**（橙，过半）/ **Normal**（蓝，正常） |
| **可通过船型** | **S**（护卫）/ **M**（巡洋）/ **L**（战列）/ **H**（货舰）/ **XL**（旗舰） |

> **这些标注是队友手工标上去的，不是自动读取的。**
> 所以：**如果你是第一个过洞的人，请务必右键这条连线，把寿命、质量、船型标上。** 这是 Wanderer 最核心的协作动作，队友全靠它判断这条洞还能不能用。

### 6.3 右键星系能做什么

| 菜单项 | 中文 | 说明 |
| --- | --- | --- |
| **Tag** | 标记 | 打一个 A–I、X/Y/Z、0–9 的单字符标记 |
| **Status** | 状态 | Clear / Home / Friendly / Looking for / Warning / Target / Dangerous |
| **Add Signature** | 添加信号 | 手动录入一个信号 |
| **Labels** | 标签 | 预设标签 `a`/`b`/`c`/`1`/`2`/`3`，或自定义标签。系统会按星系类型给建议 |
| **Set Destination** | 设为终点 | 给自己**在线**的角色设自动导航终点 |
| **Add Waypoint** / **Add Waypoint Front** | 添加路径点 / 加到最前 | 追加或插队到导航路径 |
| **Move System** / **Cancel Move** | 移动星系 | 见 6.6 |
| **Select Whole Cluster** | 选中整个星系族 | 一次性选中与该星系连通的所有星系 |
| **Add Route** / **Remove Route** | 添加/移除航线 | 加入公共航线表 |
| **Ping: RALLY** / **Cancel: RALLY** | 设置/取消集结点 | 全图广播集结点。**同一时间只能有一个** |
| **Delete** | 删除 | 删除星系（需要权限） |

最上方还有一排**快捷按钮**：打开 zKillboard、打开 Anoikis、打开 Dotlan、复制星系名、编辑星系信息。

> **你的菜单里可能少几项**，这是正常的：
> - 没有 **Lock / Unlock**（锁定只有管理员/经理能做）；
> - 没有 **Re-arrange layout**（除非该星系是 home 或你的订阅星系）；
> - **Delete** 可能不出现（取决于你的角色权限）。

**关于 `Set Destination` / `Add Waypoint`**：这是给你**自己在线角色**设 EVE 游戏内的自动导航。菜单里会先让你选「给哪个角色设」，然后才是设终点还是加路径点。**只有在线角色会出现**。

![【图 6】右键星系菜单](/images/manual/help-system-rightclick-menu.png)

### 6.4 右键连线能做什么

| 菜单项 | 中文 | 说明 |
| --- | --- | --- |
| **Life time** | 剩余寿命 | `1H` / `4H` / `4.5H` / `16H` / `24H` / `48H` |
| **Mass status** | 质量状态 | **Verge**（濒临坍塌）/ **Half**（过半）/ **Normal**（正常） |
| **Ship size** | 可通过船型 | **S** / **M** / **L** / **H** / **XL** |
| **Save mass** | 锁定质量 | 锁定后质量状态不再被自动覆盖 |
| **Set as Bridge** | 设为跳跃桥 | 只在零安↔零安的连线上出现 |
| **Disconnect** | 断开连接 | 删除这条连线 |

> 小船洞（Frigate 尺寸）不显示质量状态——因为小船洞的质量本来就没什么参考价值。

### 6.5 双击连线：看谁过过这个洞

**双击一条连线**，会打开该通道的通行记录侧栏，可以看到谁在什么时候通过了这条洞、开的什么船。

没人通过时会显示 `Nobody passed here`。

![【图 7】虫洞连线右键菜单](/images/manual/help-system-connection-rightclick-menu.png)

![【图 7】连线通行记录侧栏](/images/manual/help-system-connection-leftclick-passage.png)

### 6.6 移动星系是「两阶段」的

想调整某个星系的位置，**不是直接拖**（防止误拖），而是两步：

1. **第一步**：在要移动的星系上右键 → **`Move System`**。此时该星系进入「待移动」状态，屏幕上会提示 `Moving <星系名> — right-click an empty spot to place it.`。
2. **第二步**：在**目标位置的空白处**右键 → **`Move <星系名> here`**。

**取消**：按 **`Esc`**，或在菜单里点 **`Cancel Move`**。

落位时会**自动吸附到最近的空位**，不会和已有星系重叠。

> **在订阅视图下，移动只改你自己的本地布局，不影响别人**，所以你能随便挪。全局视图下才会移动给所有人看，那需要额外权限。

> ⚠️ **移动没有撤销。** 挪错了只能再挪一次。

## 7. 顶栏与右侧栏功能全解

### 7.1 紧凑模式的右侧栏（自上而下）

| 图标 | 悬停提示（英文） | 中文 | 作用 |
| --- | --- | --- | --- |
| 👤+ | `Tracking status` | 追踪状态 | 打开 **Track & Follow** 窗口（见第 9 章） |
| 🔍 | `Show on the map` | 在图上显示 | 打开**星系搜索**侧栏（见下） |
| # | `Show on the map` | 在图上显示 | 打开**成员分布**侧栏（见下） |

### 7.3 两个「Show on the map」的区别

新手很容易混淆，它们是**两个不同功能**：

**① 星系搜索（放大镜图标 / 菜单模式的 `TopSearch`）**

- 侧栏标题：**`Search [N]`**，输入框提示 `Type To Search`。
- 列出**你当前视图里能看到的星系**，每行显示安全等级、名称、区域、静态洞、在线/离线人数等。
- **点一行 = 聚焦并选中该星系。**
- 排序有讲究：有状态标记的排前面，然后 J 码星系优先，再按名称排。

**② 成员分布（`#` 图标 / `OnTheMap`）**

- 侧栏标题：**`On the map [N]`**，输入框提示 `Type to search`。
- 列出**当前地图上的成员**，可以按角色名、公司名、联盟名、ticker、船名、船型搜索。
- 有 **`Hide offline`** 复选框，用来隐藏离线成员。
- **点击成员可以定位到他所在的星系。**

> ⚠️ **重要：你能看到的内容受订阅范围限制。**
> 作为普通成员，**这两个列表里只会出现在你订阅视图范围内的星系和成员**。
> 管理员和经理能看到全部。所以如果你搜不到某个星系或某个人，**先想想是不是不在你的订阅范围里**——这是预期行为，不是 bug。

### 7.4 虫洞参考（Wormholes Reference）

### 7.5 集结点（Ping / Rally）

集结点是一个**全图广播的标记**，用来告诉大家「集合到这里」。

- 在星系上右键 → **`Ping: RALLY`** 设置集结点（青色信号图标）。
- 再点 **`Cancel: RALLY`** 取消。
- **同一时间全图只能有一个集结点**，已经有人设了的话，其他星系的这一项会置灰，提示 `Locked. Ping can be set only for one system.`
- 设了集结点的星系**不能被删除**，需要先取消 Ping。
- 右侧栏会有一个集结点列表，可以快速跳过去。

## 8. 悬浮窗（Widgets）

画布上那些可以**拖动、缩放、关闭**的小面板，叫 Widget。它们贴着地图显示当前选中星系的详细信息。

**默认打开 4 个**：System Info、Local、Routes、Signatures。

| Widget | 中文 | 显示什么 |
| --- | --- | --- |
| **System Info** | 星系信息 | 选中星系的名称、区域、静态洞等。没选中时显示 `System is not selected`。有铅笔按钮可以编辑星系名和描述 |
| **Signatures** | 信号 | 该星系扫描到的信号列表。表头有 `+` 可以新增信号 |
| **Local** | 本地 | 当前在该星系的角色列表。表头 `Local [N]`，可以勾 `Offline` 显示离线角色、勾 `Ship name` 显示船名、切换紧凑模式。没人时显示 `Nobody here` |
| **Routes** | 航线 | 公共航线 |
| **Routes By** | 他人航线 | 其他成员设置的航线 |
| **User Routes** | 个人航线 | 你自己的航线 |
| **Structures** | 建筑 | 该星系的建筑与计时器 |
| **Kills** | 击杀 | 该星系的击杀统计 |
| **Comments** | 评论 | 该星系的备注，支持 Markdown |

**开关这些窗格**：地图用户设置 → **Widgets** 标签，勾选想要的，然后 **Reset Widgets**（重置布局）。

> **评论有数量上限**：地图没有订阅时单星系 30 条，订阅激活后 500 条。超了会提示 `Your reach the maximum number of comments available. Please remove some comments before adding new ones.`

## 9. 角色追踪与跟随

### 9.1 什么是「追踪」

**只有被追踪的角色，位置才会显示在地图上。** 所以这是每个成员都必须做的设置。

### 9.2 在地图里开追踪

**入口**：右侧栏的 👤+ 图标（`Tracking status`），或 `Map Menu` → `Tracking`。打开 **Track & Follow** 窗口，有两个标签页：

**标签页 ① `Tracking`（追踪）**

- 表头是 `Character with tracking access`，列出你在这张图上**有权限追踪的角色**。
- **勾选要上报位置的角色**即可。支持全选。
- 如果某个角色授权异常，会有标记提示。

**标签页 ② `Follow & Settings`（跟随与设置）**

| 设置项 | 中文 | 说明 |
| --- | --- | --- |
| **Main character** | 主角色 | 你的主号。地图上某些地方会用主角色代表你 |
| **Following character** | 跟随角色 | 选定后，**地图会自动聚焦并选中这个角色所在的星系** |

> **「跟随」非常适合侦察号**：把跟随设成你的侦察号，侦察号跳到哪里，地图视角就跟到哪里。
> 取消勾选该角色的追踪，会自动清空跟随设置。

### 9.3 另一个入口：角色追踪页面

左侧导航 → **角色追踪（Characters Tracking）** 页面：

- 左侧列出你能访问的地图，**点一行选中**；
- 右侧勾选 **Tracked** 列，开启/关闭该地图上各角色的追踪。

> 不选地图时提示 `Select a map to configure character tracking`。

> ⚠️ **如果进地图时提示 `You should enable tracking for all characters that have access to this map first!`**，说明你有角色没开追踪。系统会把你引导到追踪页面，**把角色都勾上**即可。

![【图 12】Tracking 标签页](/images/manual/help-rightmenu-map-tracking.png)

![【图 12】Follow & Settings 标签页](/images/manual/help-righmenu-map-tracking-follow-and-setting.png)

## 10. 角色活跃度 Character Activity

一个**统计面板**，用来回答「这张图上谁最勤快、谁在划水」。

### 10.1 入口

- `Map Menu` → **`Character Activity`**；
- 或地图页左上角的**柱状图图标**。

### 10.2 时间范围

对话框标题形如 **`Character Activity (7 Days)`**，括号里是当前范围。点标题栏右侧的 **☰** 图标可以切换：

| 选项 | 中文 |
| --- | --- |
| **7 Days** | 最近 7 天（默认） |
| **90 Days** | 最近 90 天 |
| **1 Year** | 最近 1 年 |
| **All Time** | 全部时间 |

> **时间范围越长，数据粒度越粗。** 7 天是逐条原始记录；90 天、1 年、全部则读取按天/月/年的汇总数据。**这是有意的设计——长期统计不会因为原始数据过期而丢失**，但代价是长期范围下看不到每一条明细。

### 10.3 表格列

| 列 | 中文 | 含义 |
| --- | --- | --- |
| **Character** | 角色 | 角色名与头像 |
| **Passages** | 过洞次数 | 通过虫洞的次数（默认按这一列降序排） |
| **Connections** | 新建连接数 | 贡献了多少条新连线 |
| **Signatures** | 扫描信号数 | 扫描了多少个信号 |

点任意列头可以按该列排序。

> 统计是**按账号聚合**的：如果你有多个角色，数值会合并显示，并优先用你的「主角色」代表你。

## 12. 常见问题

**Q：进地图后一片空白，什么都没有？**
A：**九成是没订阅星系。** 去顶栏订阅栏输入你家洞的 J 码订阅一个。如果弹出了中文「订阅提醒」，照做即可。

**Q：我订阅了，但看不到某些星系？**
A：检查订阅栏左边的 **「非订阅星系族」** 是不是设成了 **「隐藏」**。隐藏模式只显示与订阅星系相连的部分。切到 **「显示」** 就能看到全部。

**Q：我的角色不在地图上？**
A：按顺序检查：① 右侧栏 👤+ → **Tracking** 里，你的角色勾上了吗；② 你的角色有没有授权、授权是否过期（角色页红色警告图标）；③ 是不是在「隐藏」模式下且角色与订阅断开。

**Q：为什么我搜不到某个星系或某个人？**
A：**普通成员只能在订阅视图范围内搜索。** 星系搜索和成员分布列表都只显示你订阅范围内的内容。这是预期行为。需要看全部的话，请管理员切换或让对方调整你的权限。

**Q：为什么我的菜单里没有 Lock / Delete？**
A：权限不同。**锁定星系只有管理员/经理能做**；删除星系需要相应权限。菜单项是按权限动态显示的。

**Q：订阅数量到上限了，加不了？**
A：取消一个已有订阅（点标签上的 `×`）再加。上限由站点配置，输入框右侧永远显示真实值。

**Q：为什么移动星系要点两次？**
A：这是**防误拖**设计。先右键 `Move System`，再到目标位置右键 `Move <星系名> here`。中途按 `Esc` 可以取消。

**Q：挪错了星系，能撤销吗？**
A：**不能。** Wanderer 没有通用的撤销功能。请再挪一次到正确位置。

**Q：我的拖动会不会影响别人？**
A：**在订阅视图下不会**——你的布局只存在你自己浏览器本地。**但如果你有全局视图权限，在全局视图下拖动会影响所有人。**

**Q：右键空白处 `Add System` 是灰的？**
A：因为你处在**「隐藏非订阅星系族」**模式。悬停会提示 `隐藏模式下不可添加星系，请先切换为「显示」`。切到「显示」即可。

**Q：地图上的连线信息（寿命、质量）是谁填的？**
A：**是队友手工填的，不是自动的。** 所以过洞之后请顺手右键连线把状态标上，这是对自己和队友都有利的事。

**Q：角色授权显示过期了怎么办？**
A：角色页面（Characters）上点 **Refresh Authorization**，重新走一遍 EVE SSO 授权。

**Q：换电脑后界面设置全没了？**
A：界面偏好默认存在浏览器本地。用 **Map user settings → Import/Export** 导出，在新电脑上导入即可。

**Q：怎么换界面配色 / 鼠标操作方式？**
A：**Map user settings → Common → Theme**，选 `Default` 或 `Pathfinder`。注意这个选项同时改变拖拽键位。
